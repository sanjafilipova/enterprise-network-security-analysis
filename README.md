# Enterprise Network Security Analysis

**Network Infrastructure | Switching & VLANs | Wireless Security | Vulnerability Assessment | Vendor Evaluation**

## Project Overview

This repository contains a collection of network design, analysis, and security assessment reports I completed as part of my **Introduction to Networking coursework through Sophia Learning**.

The project focuses on GreenLeaf Organic Foods, a fictional company with network infrastructure connecting its Portland and Eugene locations, along with plans to expand into Seattle.

Throughout these assignments, I analyzed different aspects of enterprise networking, including network topology, IP addressing, VLAN segmentation, wireless security, network monitoring, firewall configurations, VPN encryption, and vulnerability assessments.

The goal of this project was to apply networking concepts to realistic business scenarios and develop recommendations for improving network security, reliability, and performance.

## Project Reports

### 1. Network Infrastructure & Core Services

[View Network Infrastructure & Core Services](Network%20Infrastructure%20%26%20Core%20Services.pdf)

This report examines the existing network infrastructure connecting GreenLeaf's Portland and Eugene locations.

**Topics covered:**
- Network topology diagrams
- TCP, DHCP, and DNS protocols
- IP addressing and subnetting
- IPv4 and IPv6 configurations
- DHCP, NAT/PAT, and DNS services
- Site-to-site VPN connectivity

### 2. Switching, VLANs & Layer 2 Security

[View Switching, VLANs & Layer 2 Security](Switching%2C%20VLANs%20%26%20Layer%202%20Security.pdf)

This report focuses on the company's switching infrastructure and how VLANs and Layer 2 security controls help organize and protect the network.

**Topics covered:**
- Core and access switch architecture
- VLAN segmentation and 802.1Q trunking
- Spanning Tree Protocol (STP)
- Switch port security
- Network cabling and connectivity
- Layer 2 security considerations

### 3. Wireless Networking, Monitoring & Security Logs

[View Wireless Networking, Monitoring & Security Logs](Wireless%20Networking%2C%20Monitoring%20%26%20Security%20Logs.pdf)

This report analyzes GreenLeaf's wireless infrastructure, network performance monitoring, and security logging.

**Topics covered:**
- Wireless SSID and VLAN configurations
- WPA2-Enterprise and RADIUS authentication
- Wireless access point placement and channel selection
- Network monitoring using PRTG, SNMP, and NetFlow
- Quality of Service (QoS)
- Syslog analysis and suspicious network activity
- Security alerts for authentication failures, VPN outages, and port-security violations

### 4. Network Security & Vulnerability Assessment

[View Network Security & Vulnerability Assessment](Network%20Security%20%26%20Vulnerability%20Assessment.pdf)

This report evaluates network security controls and identifies weaknesses that could expose the company to security threats.

**Topics covered:**
- Network security zones and segmentation
- Vulnerability identification and risk assessment
- Firewall rules and access control
- IPsec VPN encryption and IKEv2
- 802.1X authentication
- Device hardening
- Security recommendations for SNMP, Telnet, and DHCP Snooping

### 5. Seattle Network Vendor Evaluation

[View Seattle Network Vendor Evaluation](Seattle%20Network%20Vendor%20Evaluation.pdf)

This report evaluates three network vendor proposals for GreenLeaf's planned Seattle office.

I compared the vendors based on technical capabilities, cost, reliability, qualifications, and implementation requirements.

Using a weighted scoring matrix, I recommended **Vendor B (Pacific Northwest Networking)**, which received the highest overall score of **4.20 out of 5.00**.

The recommended solution had an estimated five-year cost of **$262,660**, within the company's **$275,000 budget**.

## Key Takeaways

Working on these projects helped me develop a better understanding of how different network components work together and why security needs to be considered throughout the entire network.

One of the most important things I learned was how network segmentation, firewall rules, authentication, and monitoring can help reduce security risks.

I also learned how to analyze network weaknesses, identify suspicious activity in security logs, and recommend improvements based on technical requirements and business needs.

The vendor evaluation helped me understand that selecting network infrastructure involves more than choosing the most advanced equipment. Cost, reliability, scalability, security, and implementation requirements all need to be considered.
